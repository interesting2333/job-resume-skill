# 内置信息源与可信度

## 使用原则

- 用户原始材料、目标 JD、真实项目证据优先级最高。
- 涉及岗位定义、职业能力、市场趋势、薪资或面试方法时，优先参考权威来源。
- 社区面经、薪资爆料和培训资料只能作为趋势信号，不能当作事实结论。
- 需要最新岗位、薪资、招聘规则或平台信息时，应联网确认，并说明来源时间或样本局限。
- 不为了贴合任何信息源而编造用户经历、指标、头衔或职责边界。

## 可信度分层

| 等级 | 来源类型 | 使用方式 |
| --- | --- | --- |
| S | 用户原始材料、目标 JD、公司官网、官方职业数据库、政府统计 | 作为简历判断和岗位画像的主依据 |
| A | 大型招聘平台公开 JD、企业招聘页、开源项目文档、权威方法论 | 用于补充岗位要求、项目证据和面试方法 |
| B | 面经社区、薪资社区、行业报告、技术博客 | 用于识别趋势、常见问题和表达方式 |
| C | 社媒碎片、个人经验帖、未经验证的薪资爆料 | 只作为线索，不直接输出为确定结论 |

## 信息源路由

| 场景 | 优先来源 | 用法 |
| --- | --- | --- |
| 岗位任务、技能、知识、能力画像 | O*NET OnLine、O*NET Resource Center | 拆解职业任务、技能、知识、能力、工作活动 |
| 职业前景、学历要求、薪资、就业趋势 | BLS Occupational Outlook Handbook | 判断海外岗位趋势、典型教育要求、薪酬和相邻职业 |
| 应届生和通用胜任力 | NACE Career Readiness Competencies | 补充沟通、批判性思维、团队协作、职业素养、技术素养 |
| 结构化面试方法 | Google re:Work structured interviewing | 生成评分维度、行为追问、好答案/差答案标准 |
| 中国职业分类和新职业 | 国家职业分类大典与新职业工作平台 | 对齐国内岗位名称、职业分类和新职业描述 |
| 国内技术岗面试趋势 | 牛客、目标公司面经、招聘平台题库 | 识别高频考点和常见追问，需标注社区样本属性 |
| 海外技术岗薪酬和职级 | Levels.fyi、公司公开薪酬区间、招聘公告 | 作为谈薪参考，必须提醒样本偏差和地区差异 |
| 项目真实性和复杂度 | GitHub、README、设计文档、issue、PR、commit、测试报告 | 验证项目边界、个人贡献、技术复杂度和结果证据 |

## 输出引用规则

- 用户要求依据、最新信息、薪资、市场趋势或岗位标准时，给出来源名称和链接。
- 信息来自社区或众包平台时，明确它是样本参考，不代表市场全量。
- 如果无法联网验证最新信息，只能输出稳定方法论，不输出“当前市场价”“最新趋势”等结论。
