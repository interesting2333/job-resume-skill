# 求职指标库

## 使用原则

- 指标只能来自用户真实经历、系统记录、项目文档或可合理解释的估算口径。
- 没有精准数字时，不编造；可降级为范围、频率、量级或变化方向。
- 指标必须能解释口径：统计范围、时间窗口、对照基准、数据来源。

## 技术岗

| 方向 | 可用指标 |
| --- | --- |
| 性能 | 延迟 P50/P95/P99、吞吐、QPS、响应时间、CPU/内存/IO、构建耗时 |
| 稳定性 | 可用性、错误率、失败率、MTTR、告警数、事故次数、回滚次数 |
| 数据 | 数据量、表规模、同步延迟、任务成功率、数据准确率、报表出数时间 |
| 工程效率 | 发布频率、部署耗时、测试覆盖率、缺陷率、自动化率、交付周期 |
| 架构治理 | 服务数、接口数、依赖数、接入团队数、统一规范覆盖率 |
| 安全合规 | 漏洞数、权限误配、审计覆盖、风险处置时长 |

## 产品岗

| 方向 | 可用指标 |
| --- | --- |
| 用户 | DAU/MAU、活跃率、留存、流失率、用户满意度、NPS |
| 转化 | 漏斗转化率、注册率、下单率、支付率、试用转正率 |
| 商业 | GMV、收入、客单价、复购率、毛利、成本下降 |
| 交付 | 需求吞吐、上线周期、延期率、跨团队协作周期 |

## 运营岗

| 方向 | 可用指标 |
| --- | --- |
| 增长 | 拉新、获客成本、转化率、裂变率、渠道 ROI |
| 内容 | 阅读、点击、互动、完播、转发、收藏、内容产能 |
| 活动 | 参与人数、转化、留存、复购、预算消耗、ROI |
| 用户 | 分层规模、召回率、沉默用户激活、社群活跃 |

## 数据分析岗

| 方向 | 可用指标 |
| --- | --- |
| 分析产出 | 指标体系覆盖、看板数量、使用团队、决策采纳 |
| 实验 | AB 实验数量、显著性、样本量、实验周期、提升幅度 |
| 数据质量 | 准确率、缺失率、延迟、异常发现时长、修复时长 |
| 业务影响 | 成本降低、收入提升、效率提升、风险减少 |

## 管理岗

| 方向 | 可用指标 |
| --- | --- |
| 团队产出 | 交付数量、质量、延期率、重点项目完成率 |
| 组织效率 | 协作周期、流程耗时、重复问题减少、人效 |
| 人才培养 | 晋升、梯队、招聘、留存、培训覆盖 |
| 机制建设 | 规范覆盖、复盘机制、质量门禁、风险预警 |

## 无精确数据时的降级表达

可使用：

- 高频/低频、分钟级/小时级/天级。
- 单团队/多团队/全公司。
- 核心链路/关键系统/基础设施。
- 从手工到自动化、从分散到统一、从不可观测到可追踪。
